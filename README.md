# Website Launch Checklist

A practical, no-fluff checklist to review before and after launching a website.
Covers SEO, performance, accessibility, security, tracking and conversion.

Works for WordPress, Shopify, Webflow, React and custom-built sites.

![License: MIT](https://img.shields.io/badge/license-MIT-green.svg)
![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)

## Why this exists

Most website problems found after launch (missing meta tags, broken forms,
slow mobile pages, no analytics) could have been caught with a simple review.
This checklist gives teams and freelancers one place to check everything.

## How to use it

1. Copy [`CHECKLIST.md`](./CHECKLIST.md) into your project management tool,
   or fork this repo.
2. Go through each section before launch.
3. Re-run the post-launch section after 7 days and again after 30 days.

## Quick overview

| Area | What it covers |
|---|---|
| Content & UX | Clear messaging, navigation, calls to action, forms |
| SEO basics | Titles, meta descriptions, headings, sitemap, robots.txt |
| Performance | Image formats, caching, Core Web Vitals |
| Accessibility | Alt text, contrast, keyboard navigation |
| Security | HTTPS, backups, updates, form spam protection |
| Tracking | Analytics, conversion events, Search Console |
| Post-launch | Monitoring, indexing, fixes, reviews |

## Tools that help

- [Google PageSpeed Insights](https://pagespeed.web.dev/): performance and Core Web Vitals
- [Google Search Console](https://search.google.com/search-console): indexing and search performance
- [WAVE](https://wave.webaim.org/): accessibility checks
- Lighthouse in Chrome DevTools: audits for performance, SEO and accessibility
